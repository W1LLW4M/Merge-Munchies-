# 🍭 Merge Munchies 🌈

**Welcome to Merge Munchies — where merging gets MUNCHY!**

Dive into a colourful world of satisfying merges, exciting upgrades, and delicious surprises. Combine items, discover new creations, and explore a vibrant game experience packed with animations and fun!

## ✨ Features

- 🌈 **Rainbow-Themed World** — Enjoy a bright, colourful interface filled with vibrant visuals.
- 🍬 **Merge Gameplay** — Combine items and discover new possibilities.
- 🎰 **Luck System** — Explore your luck and see what surprises await!
- 🎨 **Smooth Animations** — Enjoy satisfying effects, transitions, and interactive elements.
- 🗺️ **Multiple Sections** — Navigate between different areas of the game using the top navigation buttons.
- 🖥️ **Full-Screen Experience** — A game interface designed to fill your screen.
- ✨ **Interactive UI** — Click, explore, and discover what Merge Munchies has to offer.

## 🎮 How to Play

1. Open Merge Munchies.
2. Explore the different sections using the navigation buttons at the top.
3. Try out the available features and systems.
4. Merge, discover, and experiment!
5. Have fun and see what you can unlock.

## 🚀 Getting Started

### Play Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

No complicated setup required!

```bash
git clone YOUR_REPOSITORY_URL
```

Replace `YOUR_REPOSITORY_URL` with the URL of this repository.
